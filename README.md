# Лабораторная работа 2

## Тема
Разделение приложения на frontend- и backend-сервисы с использованием API Flask и Flask

## Описание
Проект состоит из двух независимых сервисов:
- backend предоставляет API и документацию OpenAPI
- frontend обращается к backend и отображает полученные данные в браузере

## Технологии
- Python 3.x
- Flask
- Flask-RESTX (или Flask-Smorest)
- Requests (для frontend)
